# ♟️ Python Chess Game

A feature-rich Chess Game built using **Python** and **Tkinter**, featuring an AI opponent, smooth animations, multiple themes, and an interactive chessboard.

## ✨ Features

- 🤖 **AI Opponent** – Play against computer AI.
- 🎯 **Three Difficulty Levels** – Easy, Normal, and Hard.
- ♟️ **Legal Chess Moves** – Powered by python-chess.
- 🎨 **Multiple Board Themes** – Classic, Wood, Emerald, and Midnight.
- 🎬 **Smooth Move Animations** – Animated piece movement.
- 📜 **Move History** – View your previous moves.
- ♙ **Captured Pieces Display** – Track captured pieces.
- ↩️ **Undo Moves** – Take back moves.
- 💾 **PGN Support** – Save and load chess games.
- 🔄 **Board Rotation** – Change the board orientation.
- 🔊 **Sound Settings** – Enable or disable game sounds.

## 🛠️ Technologies Used

- Python
- Tkinter
- python-chess

## 🚀 Installation & Setup

**1. Install Python**

Make sure Python is installed on your computer.

**2. Install the required library**

Open your terminal and run:

```bash
pip install python-chess
```

**3. Run the game**

Navigate to the project folder and execute:

```bash
python chess_game.py
```

## 🎮 Game Modes

Play chess against the AI and choose between Easy, Normal, and Hard difficulty levels.
